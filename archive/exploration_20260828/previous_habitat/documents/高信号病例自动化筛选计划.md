# T2WI高信号病例自动化筛选计划

## 一、目的与当前结论

本筛选用于识别肿瘤内确实存在“信号强度不低于瘤周脂肪”的实质性高信号成分，并替代原先“存在大于0.5倍脂肪信号成分即可”的宽松人工入组标准。

全队列结局盲审计显示，原入组病例中多数可找到少量达到脂肪均值的体素，但相当一部分仅表现为零散、微小或接近肿瘤边缘的高信号体素，不足以支持临床意义上的高信号表型。推荐采用“信号阈值＋相对占比＋连通体积＋肿瘤内部延伸”的联合规则，不采用未经标准化的原始体素计数作为唯一标准。

原始主清单和全部病例记录均保留，不物理删除病例。筛选结果同时形成严格集和相对宽松集：严格集保留原推荐联合规则，宽松集按当前项目决定作为主分析入口；两套数据集均不改变原A/B归属。

## 二、数据边界

- R1主队列：693例，其中A集530例、B集163例；全部病例均有肿瘤、脂肪和肌肉ROI。
- R2：30例双读者病例中29例可计算；IMG-8BF8DD5DE4的R2缺少可用脂肪ROI。可计算病例中27例R1/R2为同序列。
- 入组判定仅使用R1。R2只用于评价筛选规则和生境划分的技术重复性。
- 不读取DFS、OS、治疗、病理或任何模型预测结果。阈值在结局分析前锁定。

## 三、自动测量定义

### 3.1 图像和ROI

- 使用原始R1 T2WI及同一图像上的多标签ROI。
- 肿瘤ROI为标签1，瘤周脂肪ROI为标签2。
- 主阈值直接在原始图像上计算，不进行N4或跨病例灰度标准化。脂肪和肿瘤来自同一图像，乘法性信号缩放不会改变二者的相对关系。
- 图像与掩膜必须几何一致；脂肪ROI必须非空、信号有限且体素数不少于200。脂肪ROI均值与10%截尾均值或面内侵蚀1体素后的均值相差超过10%时，标记为脂肪参考QC异常，提交人工复核。

### 3.2 高信号体素

对每例计算瘤周脂肪ROI平均信号强度 \(\bar S_{fat}\)。肿瘤内满足下式的体素定义为高信号候选体素：

\[
S_{tumor}(v) \geq \bar S_{fat}
\]

同时记录：

- 肿瘤和脂肪体素数、物理体积；
- 脂肪均值、中位数、10%截尾均值、标准差及面内侵蚀后均值；
- 高信号体素数、物理体积、占肿瘤比例；
- 折算到`1×1×2 mm`标准网格的等效体素数；
- 26邻域最大连通成分体积及其占全部高信号体积的比例；
- 高信号体素距肿瘤边界的1、2和3 mm内部体积、平均深度和最大深度。

绝对阈值使用物理体积。原始数据体素体积中位数为0.408 mm³，P90为1.289 mm³；直接要求“原始体素≥64个”会随扫描分辨率变化。实际数据中，原始64体素规则保留411例，而等效于标准网格64体素的128 mm³规则仅保留261例，两者有150例判定不一致。

## 四、全队列测量结果

|候选规则|全队列保留|A集保留|B集保留|
|---|---:|---:|---:|
|至少1个肿瘤体素≥脂肪均值|635/693（91.6%）|498/530（94.0%）|137/163（84.0%）|
|高信号占比≥0.1%|500/693（72.2%）|393/530（74.2%）|107/163（65.6%）|
|高信号占比≥0.5%|314/693（45.3%）|251/530（47.4%）|63/163（38.7%）|
|高信号占比≥1%|243/693（35.1%）|200/530（37.7%）|43/163（26.4%）|
|标准网格等效高信号体素≥64个（≥128 mm³）|261/693（37.7%）|216/530（40.8%）|45/163（27.6%）|
|推荐联合规则|160/693（23.1%）|137/530（25.8%）|23/163（14.1%）|

共有58例完全没有达到脂肪均值的肿瘤体素，其中A集32例、B集26例。全队列高信号占比中位数为0.376%，P75为2.11%；高信号物理体积中位数为55.5 mm³，P75为371.2 mm³。该分布说明“存在任意高信号体素”不能区分临床意义上的高信号成分。

脂肪均值具有较好的内部稳健性：相对于原始均值，10%截尾均值的绝对相对差异中位数为0.75%、P95为1.82%，二者在“是否存在任意高信号体素”上的判定仅5例不一致；面内侵蚀后脂肪均值与原始均值的差异中位数为2.05%、P95为5.17%，任意高信号判定15例不一致。因此原始脂肪均值可作为主参考，截尾均值和侵蚀均值用于QC敏感性检查。

## 五、筛选规则与数据集版本

### 5.1 严格筛选规则（保留为次要/敏感性数据集）

每例必须同时满足：

1. 肿瘤内存在信号强度不低于脂肪ROI均值的体素；
2. 高信号体素占肿瘤总体素比例≥1%；
3. 高信号体素的最大26邻域连通成分体积≥128 mm³，相当于`1×1×2 mm`网格上的64体素；
4. 距肿瘤ROI边界至少2 mm的高信号体积≥32 mm³，相当于标准网格上的16体素。

第3条同时保证了绝对数量和空间聚集性，第4条排除全部局限于肿瘤外围的候选体素。当前数据中，通过第2和第3条的病例均达到第4条，但第4条仍作为跨队列和未来病例的固定防护条件保留。

严格规则保留160例。A/B保留比例差异明显；样本量不少于10例的B集设备组保留率为9.1%–23.5%，整体仍低于A集GE MR750 3T的25.7%。这可能同时反映病例构成和采集参数差异。筛选规则不得针对B集重新调节；B集保留率仅用于泛化风险说明。严格集保留为次要/敏感性数据集，不作为当前主分析入口。

### 5.2 主分析相对宽松规则（当前锁定）

主分析集采用预先指定的相对宽松规则，每例同时满足：

1. 肿瘤内至少存在1个信号强度不低于脂肪ROI均值的体素；
2. 满足上述阈值的高信号体素占肿瘤总体素比例≥0.1%（0.001）。

该规则不附加连通成分、内部深度或物理体积门槛，保留原始研究对象中具有可量化高信号成分的病例，并排除肿瘤内完全没有达到脂肪均值体素的病例。当前全队列保留500例，其中A集393例、B集107例。宽松集用于后续基线检查、预处理、临床/影像组学/生境主分析及A→B验证；严格集用于预先定义的敏感性分析。两套数据集共享同一特征版本、结局定义、A/B划分和嵌套交叉验证规则。

### 5.3 其他预设敏感性规则

用于验证结论是否依赖较严格阈值，不用于根据预后结果选择队列：

- 高信号总体积≥128 mm³；
- 高信号占比≥0.5%；
- 最大连通成分≥64 mm³；
- 距边界≥2 mm的高信号体积≥16 mm³；
- 最大连通成分在距边界≥2 mm区域内的体积≥8 mm³。

该规则保留189例（A集157例、B集32例）。主分析与敏感性分析的阈值均须在读取结局前锁定。

## 六、双读者与既有生境结果的解释

严格筛选规则在27例同序列可计算R1/R2病例中的筛选一致率为88.9%，Cohen κ为0.743；R1通过9例、R2通过8例、两者均通过7例。

将R1严格筛选结果应用于既有22例A集技术试点后，仅9例保留。在6 mm患者内K=2分支中：

- H-low Dice中位数为0.886；
- H-high Dice中位数为0.904；
- H-high体积分数ICC(2,1)为0.795。

该结果支持“此前技术不合格至少部分由宽松入组导致”的解释，但属于筛选后小样本探索，不能直接推翻原技术门槛结论，也不能据此冻结6 mm方法。当前有效配对数不足，需重新建立富集高信号阳性病例的双读者技术验证集。

## 七、执行工作流

```text
锁定脂肪参考、宽松主分析规则和严格敏感性规则
→ 对693例生成R1筛选标记，不删除原始病例
→ 逐例复核脂肪参考QC异常和阈值附近病例
→ 由影像导师盲法抽查明确阳性、明确阴性和临界病例
→ 确认最终表型规则
→ 在主清单新增筛选状态、各项测量值和排除原因
→ 保持原A/B归属不变，同时生成宽松主分析集和严格敏感性集
→ 以宽松主分析集检查样本量及3年/5年事件数
→ 对严格敏感性集同步记录样本量及3年/5年事件数
→ 建立至少20例可计算阳性的独立双读者技术集
→ 在该技术集重跑患者内K=2的4/6/8 mm门槛试验
   ├─ 不合格：停止生境建模
   └─ 合格：锁定尺度和标签规则
→ 仅在锁定后对宽松高信号A集提取生境特征并建模
→ 一次性应用到宽松高信号B集
→ 用相同冻结参数在严格敏感性A/B集重复评估
```

### 7.1 人工复核抽样

人工复核不替代自动规则，只验证规则的临床对应性。建议从R1中分层抽取：

- 严格规则阳性且远离阈值者10例；
- 推荐规则阴性且所有指标远低于阈值者10例；
- 任一指标位于阈值±20%范围内的临界病例20例；
- A/B及主要设备组均应覆盖。

复核者只判断是否存在临床可识别的、达到脂肪信号且非纯外围的高信号成分，不查看结局、既有模型或筛选后生境指标。若临界病例系统性错分，应在读取结局前一次性修订规则并重新全队列计算。

### 7.2 双读者技术集

现有技术试点按严格规则仅剩9例R1阳性，无法满足稳定ICC评估。建议从160例严格阳性病例中分层选择至少30例重新完成R2肿瘤、脂肪和肌肉ROI，目标为获得不少于20例同序列、脂肪参考完整且双读者均可计算的阳性配对。病例选择按A/B、设备、肿瘤体积和高信号占比分层，不根据生境Dice或预后选择。

## 八、批准规则后的项目影响

- 主清单新增筛选字段并保留全部693例原始记录；不物理删除病例。
- 宽松主分析集包含500例，其中A集393例、B集107例；严格敏感性集包含160例，其中A集137例、B集23例。两套数据集均须核查3年/5年事件数及置信区间可接受性。
- 队列定义会影响临床模型、常规影像组学模型和生境模型的目标人群。主分析应重新生成宽松集的基线表、训练/测试数据、预处理和所有模型评价；严格集仅按相同冻结流程进行敏感性重跑。
- 阈值附近病例、脂肪参考QC异常和缺失脂肪ROI病例需保留明确的审计状态，不能静默归入阴性。
