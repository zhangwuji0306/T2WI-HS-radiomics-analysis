# 生境技术门槛判定与后续工作流

## 一、判定结论

当前预设的“肌肉归一化＋三维SLIC＋全A共享K=2聚类中心”流程判定为**技术不合格**。

因此：

- 不冻结当前生境生成流程；
- 不提取全A生境内影像组学；
- 不启动H1–H5生境预后建模；
- 不生成或查看B集生境结果；
- 当前结果作为预设方法的无结局技术可行性结果保留。

## 二、判定数据边界

- 数据：A集中22例同序列R1/R2配对病例。
- 影像：当前主预处理为肌肉均值归一化、`[1,1,2] mm`、无N4。
- 技术候选：SLIC 4、6、8 mm；K=2主技术臂；K=3、`[2,2,2] mm`、N4和ROI扰动敏感性臂。
- 结局边界：仅从A建模表读取影像号，不读取DFS、临床变量或治疗后变量；不读取B集。

## 三、主技术臂门槛核对

| H-high体积分数ICC(2,1) | 0.828 | 0.803 | 0.868 | ≥0.75 | 三尺度通过 |
| H-low Dice中位数 | 0.958（21例可算） | 0.850（22例可算） | 0.921（22例可算） | ≥0.70 | 三尺度通过 |
| H-high Dice中位数 | 0.707（17例可算） | 0.398（20例可算） | 0.643（20例可算） | ≥0.70 | 仅4 mm在可计算病例中达到阈值 |

除H-high体积分数外，多数空间描述符未达到0.75；部分指标因空生境缺少有效配对。当前描述符体系不具备整体进入预后建模的重复性基础。

### 3.2 敏感性分析结论

- K=3的H-high Dice中位数为0.277–0.408，纹理不可计算比例为86.4%–95.5%，不构成替代方案。
- 2 mm各向同性重采样出现13–20/22例空生境，不能改善主要问题。
- N4出现6–13/22例空生境，H-high Dice仍未稳定达到0.70。
- ROI膨胀在6 mm时空生境降至2/22，但H-high Dice为0.346、H-high体积分数ICC为0.717；ROI侵蚀亦未同时通过核心门槛。

没有敏感性分支同时满足体积分数ICC、两类生境Dice、空生境比例和描述符重复性要求。

### 3.3 设备指标

22例A集技术试点均来自GE DISCOVERY MR750 3T，无法在A集内估计设备与生境比例的关系。该指标不作为本次失败的原因，但不能被判定为通过；应在流程锁定后仅于B集作描述性泛化评价，不参与技术选择。

## 四、失败模式解释

主要失败模式是全A共享聚类中心不能保证每个肿瘤都同时包含两个生境。部分患者的全部超体素均靠近同一全局中心，形成空生境或极小生境。结果表现为：

1. H-high体积分数总体可重复，但个体空间划分不稳定；
2. H-high Dice、ARI和空间描述符ICC偏低；
3. 大量病例不满足生境内纹理计算的最小体积要求；
4. 重采样、N4和ROI扰动不能一致纠正该问题。

这说明当前全局绝对信号分群更接近跨患者强度分层，尚不能稳定表达目标所需的“患者肿瘤内部相对高、低信号异质性”。

## 五、后续分析原则

当前结果不适合通过继续调尺度、放宽阈值或删除失败病例进入建模。后续若继续生境研究，应先完成一次明确记录的方案修订，重新进行无结局技术试点。

修订后的生境含义调整为：

- `H-high`：同一患者肿瘤内部相对高信号生境；
- `H-low`：同一患者肿瘤内部相对低信号生境。

两类标签仍按肌肉归一化T2平均信号排序，但不再解释为跨患者统一的绝对强度类别。

## 六、修订技术方案

### 6.1 保持不变的部分

- A/B队列定义、DFS终点和3年/5年评价时点；
- R1用于建模，A集同序列R1/R2用于技术重复性；
- 肌肉均值归一化、`[1,1,2] mm`重采样、无N4；
- 三维SLIC空间单元和4、6、8 mm候选尺度；
- 固定随机种子、无结局技术选择和B集隔离；
- 生境最低纹理要求：≥64体素、≥0.5 mL、≥4个有效灰度箱。

### 6.2 修订的聚类方法

主候选改为患者内K=2聚类：

1. 每例独立对肿瘤内SLIC超体素平均肌肉归一化T2信号执行K-means；
2. 固定K=2、k-means++、`n_init=100`和随机种子；
3. 按两个患者内聚类中心由低到高标记H-low/H-high；
4. 不强制改写过小生境，不用人为体积分位数保证通过；
5. 记录两类中心、体积分数、绝对体积和中心间距，维持信号对比度的可解释性。

预设敏感性方法为患者内Otsu阈值分割超体素均值。Otsu仅用于判断患者内K=2结果是否依赖聚类算法，不根据预后性能选择方法。K=3不再作为下一轮主候选。

### 6.3 修订后的技术门槛

同一尺度必须同时满足：

1. 两个生境的Dice中位数均≥0.70；空生境、过小或失败病例按Dice=0计入，不从中位数中删除；
2. 空生境或无法分配比例<10%；
3. H-high体积分数ICC(2,1)≥0.75；
4. 无几何错位和标签方向错误，22例叠加图完成逐例复核；
5. 单个低维描述符仅在ICC≥0.75且有效配对≥20/22时准入；
6. 至少保留H-high体积分数及一个信号或空间描述符，才建立描述符模型；
7. 生境内高维组学仅在全A-R1中两个生境均满足纹理要求的病例比例≥90%时进入主模型，否则取消高维主分支。

4、6、8 mm均先独立判定。若多个尺度通过，选择两类生境中较低Dice中位数最高者；差值<0.02时优先6 mm。若没有尺度通过，终止生境预后建模，不再增加算法候选。

## 七、修订后的执行工作流

```text
记录当前全局聚类技术失败
→ 冻结修订技术候选与新门槛，不读取结局或B集
→ 在同一22例A集R1/R2上运行患者内K=2（4/6/8 mm）
→ 完成患者内Otsu、2 mm、N4及ROI扰动敏感性
→ 逐例复核叠加图并计算含失败病例的Dice、ICC及失败率
→ 第二次技术门槛判定
   ├─ 不合格：终止生境预后建模，报告技术不可行结果
   └─ 合格：锁定一个尺度和患者内标签规则
→ 生成全A-R1低维生境描述符
→ 核查全A生境纹理可计算比例
   ├─ 不足90%：仅保留描述符模型
   └─ 达到90%：提取Original生境内组学并执行R1/R2 ICC筛选
→ 构建A集模型：H1临床、H2稳定描述符、H4临床＋稳定描述符
   └─ H3高维生境组学仅在纹理准入后作为次要模型
→ A集一次外层5折试运行，计算3年和5年OOF AUC
→ 根据A集技术完整性、H4−H1方向及校准决定是否进入50×5正式内部验证
→ 使用全A锁定最终流程
→ 一次性应用于B集并报告3年/5年AUC、校准、Brier/IBS及设备分层描述
→ 进入稿件写作
```

## 八、A集建模分支

下一轮技术试点通过后，模型优先级调整为：

1. H1：9个预设临床影像学变量；
2. H2：通过ICC门槛的低维生境描述符；
3. H4：9个临床变量强制纳入＋稳定生境描述符惩罚；
4. H3：仅在全A纹理准入和生境特征ICC筛选均通过后评估；
5. H5：暂缓，不在首次A集快速检查中运行。

快速检查同时报告3年和5年OOF AUC。若H2接近随机且H4在两个时点均不优于H1，停止生境路线；若改善方向一致但幅度或不确定性不足，进入50×5内部验证；只有内部验证稳定、校准不恶化且特征选择可复现时，才锁定流程并进入B集。

## 九、第二次技术门槛判定（患者内相对生境）

修订方案在同一22例A集同序列R1/R2上完成了结局盲技术试点，共396条病例—尺度—分支指标，运行时间969.9秒。主方法为患者内K=2；Otsu、`[2,2,2] mm`、N4和ROI侵蚀/膨胀作为敏感性分支。

|主方法尺度|H-low Dice中位数（22例）|H-high Dice中位数（22例）|空/失败比例|H-high体积分数ICC(2,1)|核心门槛|
|---:|---:|---:|---:|---:|:---|
|4 mm|0.823|0.845|0.0%|0.440|不合格|
|6 mm|0.834|0.773|0.0%|0.520|不合格|
|8 mm|0.799|0.649|0.0%|0.537|不合格|

本次结论为**技术不合格**。虽然4 mm和6 mm的两类生境Dice达到0.70，且所有病例均成功分配两个生境，但三种尺度的H-high体积分数ICC均明显低于0.75；因此没有尺度满足全部核心门槛。患者内Otsu与K=2的结果基本一致，说明失败主要来自R1/R2生境体积分数和空间划分的读者不一致，而不是K-means实现本身。`[2,2,2] mm`、N4及ROI扰动未同时改善重复性和门槛指标。

描述符层面，主方法全部6类低维描述符的ICC均未满足“ICC≥0.75且有效配对≥20/22”；最高值为H-high连通成分密度0.684（6 mm）。R1两类生境同时达到纹理最低要求的比例为4 mm和6 mm各86.4%、8 mm为100%，但8 mm的H-high Dice和描述符ICC仍不合格，故不能进入高维生境组学主分支。6 mm主方法R1/R2叠加图已完整输出于修订试点QC目录；定量门槛已足以作出不合格判定，不以主观挑选病例改变结论。

## 十、判定后的工作流程

1. 将修订试点的`case_selection.csv`、`pair_metrics.csv`、`summary.csv`、`descriptor_icc.csv`、QC叠加图和运行清单作为结局盲技术审计附件保存。
2. 本项目停止生境特征提取、H1–H5生境预后建模、快速AUC检查及B集生境验证；不再通过增加尺度、放宽失败定义或继续尝试聚类算法来寻求技术通过。
3. 主研究回到已批准的非生境分析主线：临床模型、常规肿瘤ROI影像组学及其预设的3年/5年内部验证；本次生境结果作为“技术可行性未达标”的探索性结果，不作为预测模型特征来源。
4. 如后续仍希望开展生境研究，需另行形成方法学修订记录并由影像组学导师预审，至少重新评估R1/R2配准、ROI一致性、强度标准化和患者内标签稳定性；新方案须在独立的结局盲重复性队列通过同等门槛后，才可重新进入预后建模。
5. 在当前项目稿件写作前，报告应明确：技术门槛在患者内K=2/Otsu及全部预设敏感性分支下均未通过，未进行生境结局建模或B集应用，避免将技术失败误写为预后阴性结果。
