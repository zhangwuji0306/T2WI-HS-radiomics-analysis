## 总体顺序

```text
分析冻结
→ v2全量特征提取与QC
→ stage6_v2候选池
→ modeling_v2建模数据
→ A集一次重复试运行
→ 快速检查：A的AUC → 锁定模型 → B的AUC
→ 分支决策
→ A集完整嵌套交叉验证
→ 正式性能评价与敏感性分析
→ 结果、表格和图形冻结
→ 进入稿件写作
```

## 一、分析前冻结

在查看任何新模型性能前确认：

- 主终点为DFS，快速检查主时间点为3年DFS。
- A=MR750 3T，B=其他设备，定义不再调整。
- 主分析为肌肉均值归一化、`1×1×2 mm`、`f=0.25`、不启用N4。
- 临床影像学变量固定为9个；性别、length、distance不进入任何主模型。
- Model 1/2/3、ICC阈值、插补、折内筛选、`lambda.1se`和随机种子全部冻结。
- B只能用于一次性设备留出验证，不得据其结果调参或选择特征。

## 二、完成v2影像组学产物

依次完成：

1. 主分析和预设敏感性分析的全量预处理。
2. Original、Wavelet、LoG特征提取。
3. 核查每个分析臂的病例数、读者数、特征数、缺失、异常、重复列和固定箱宽。
4. 核查B超出A参考强度范围的比例，但不裁剪B。
5. 完成`[2,2,2] mm`各向同性重采样敏感性臂。

只有主分析产物完全通过QC，才能进入后续阶段；敏感性臂可以在快速检查之后再全量建模。

## 三、生成stage6_v2候选池

- 在A内同序列双读者病例计算ICC(2,1)，保留`ICC>0.75`。
- 剔除A-R1存在缺失值的特征。
- B双读者结果只作描述。
- 不在全A提前执行近零方差筛选、相关去重或标准化；这些步骤仍在外层训练折内完成。
- 输出各特征的来源、ICC、剔除原因和候选状态。

## 四、构建modeling_v2数据

合并临床资料、结局和v2候选特征，核查：

- A/B病例数和DFS事件数；
- 9个临床影像学变量的编码与缺失；
- 性别、length、distance未进入预测矩阵；
- 组学特征无缺失、重复列或病例错配；
- 中文审计列与R使用的ASCII列一一对应；
- A、B的数据列完全一致，B中不存在额外拟合参数。

## 五、A集一次重复试运行

先执行一次完整的外层5折嵌套交叉验证，目的主要是验证流程，而不是形成正式结论：

- 三个模型共享相同外层折。
- 每个训练折完成MI、近零方差筛选、相关去重、标准化和内层λ选择。
- 验证折只使用训练折参数。
- 生成A的OOF预测。
- 检查MI收敛、每折事件数、候选数、非零特征数、预测缺失和异常风险值。

技术失败时应停止，不计算B的AUC。

## 六、快速检查分支

### 6.1 快速检查的计算内容

建议同时保存两种A集AUC：

- `A_apparent_AUC`：全A最终拟合模型在A上的表观3年AUC，用于观察拟合程度。
- `A_OOF_AUC`：一次重复嵌套CV产生的OOF 3年AUC，用于初步估计泛化性能。

随后使用全A拟合并锁定的Model 1/2/3直接预测B，计算：

- B的3年DFS AUC；
- Model 3−Model 1的AUC差值；
- A与B的样本数、事件数及3年在险人数。

快速阶段只需要点估计，不运行1000次正式bootstrap，也暂不制作校准曲线和DCA。

### 6.2 快速检查的推荐预警标准

这些只是运行决策标志，不是统计学成功标准：

| 指标 | 预警 |
|---|---|
| A OOF AUC接近0.50 | 模型缺乏明显区分能力 |
| A表观AUC−OOF AUC >0.05 | 可能过拟合 |
| 差值 >0.10 | 严重过拟合预警 |
| B AUC较A OOF下降 >0.10 | 明显设备迁移或泛化问题 |
| Model 3−Model 1≤0 | 未观察到影像组学增量 |
| 预测缺失、方向颠倒或极端集中 | 技术或编码问题，结果无效 |

## 七、快速检查后的分支处理

| 结果模式 | 后续处理 |
|---|---|
| 技术失败、预测缺失或模型未收敛 | 停止；检查编码、病例对应、插补、方向、时间单位和实现。修复后从A重新运行，暂不查看B |
| A表观较好但OOF明显下降 | 优先判断过拟合；检查折内筛选是否泄漏、相关去重、标准化、λ和候选特征数量。仅根据A修改并重新冻结后再运行 |
| A的三个模型均表现较弱 | 检查终点时间、事件编码、随访起点和数据合并；若无错误，接受预测信号有限，不进行事后特征挖掘 |
| Model 1尚可，Model 2/3无改善 | 影像组学可能没有增量价值；继续正式分析并如实报告，不能根据B另选特征 |
| Model 2较好、Model 3改善有限 | 检查临床变量与组学特征重叠、惩罚和非零特征稳定性；后续仅执行已预设的统一惩罚和Elastic Net敏感性分析 |
| A较好、B明显下降 | 先核查A/B预处理、变量编码、缺失处理和设备分布；无客观错误时将其解释为设备泛化不足，禁止用B重新筛选或调参 |
| A较弱、B反而较好 | 考虑B事件数较少导致的随机波动；进入完整嵌套CV和bootstrap，不据此提升模型评价 |
| A/B均可，但Model 3不优于Model 1 | 正式结论可能是影像组学未提供增量价值，仍完成预设性能和敏感性分析 |
| A/B均可且Model 3稳定优于Model 1 | 进入完整正式分析 |

客观的数据或程序错误可以修正后重跑，但必须记录错误、影响范围和修正时间。若根据B的AUC主动改变特征、λ、模型或主分析方案，B将不再是独立验证集，只能降级为探索性数据，并需要新的验证队列。

## 八、完整正式分析

快速分支通过或决定继续后：

1. 在A执行外层5折×50次重复嵌套CV。
2. 报告Model 1/2/3的OOF C-index和1/3/5年AUC。
3. 汇总非零特征数、入选频率及模型稳定性。
4. 使用已锁定的全A模型和已保存的B预测完成正式评价，不重新调参。
5. 通过患者级配对bootstrap获得性能及Model 3−Model 1差值的95%CI。
6. 评价A和B的校准、Brier/IBS及探索性DCA。
7. 描述OPTIMA和MULTIVA两个主要B设备组；不根据设备分层结果选择模型。

## 九、敏感性与探索性分析

主分析完全锁定后，依次完成：

- 完整病例；
- `lambda.min`；
- Elastic Net `α=0.9`；
- muscle `f=0.1`、Z-score `f=0.25/0.1`；
- `[2,2,2] mm`各向同性重采样；
- mrT/mrN哑变量；
- 所有变量统一惩罚；
- 年龄/EID自然样条；
- 完全不使用结局的部署型插补；
- OS、CSS及预设探索性模型。

任何敏感性分析都不能因为B表现较好而被重新指定为主分析。

- B设备分层结果；
