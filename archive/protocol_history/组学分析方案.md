# 组学分析方案（直肠癌 T2 加权 MRI）

## 一、研究目标与范围

本研究基于治疗前直肠癌 T2 加权 MRI 和肿瘤三维 ROI 提取影像组学特征，评估特征的观察者间可重复性，并建立预后模型。影像组学处理采用预设主分析与敏感性分析；训练集用于确定全部数据驱动参数和特征筛选规则，外部测试集仅用于锁定模型的独立验证。

### 1.1 数据组成

- `feature_extract/result/`：693 例读者 R1 图像及 ROI。
- `feature_extract/reader_2_result/`：30 例读者 R2 图像及 ROI，为 R1 队列子集。
- 图像与掩膜格式：NRRD。
- 多标签掩膜：0=背景、1=肿瘤、2=脂肪、3=肌肉。肿瘤标签 1 为唯一特征提取 ROI；肌肉 ROI 用于主分析的强度归一化。
- 采集参数：层厚 2.5–5.5 mm，中位数 3.3 mm；面内体素间距 0.31–1.02 mm，中位数 0.35 mm。
- 高信号表型筛选在 R1 原始图像上完成：肿瘤内至少有1个体素信号强度不低于瘤周脂肪 ROI 均值，且此类高信号体素占肿瘤总体素比例≥0.1%。筛选只生成状态和测量记录，不物理删除原始病例。

### 1.2 训练集与外部测试集

- 主分析宽松集：500 例，其中训练集 A（GE DISCOVERY MR750 3T）393 例，外部测试集 B（其余设备）107 例。筛选后 B 包括 GE OPTIMA MR360 1.5T 67 例、Philips MULTIVA 1.5T 37 例、UIH uMR 790 3T 2 例和 SIEMENS AERA 1.5T 1 例；具体设备计数以筛选后清单为准。
- 严格敏感性集：160 例，其中 A 137 例、B 23 例，采用高信号占比≥1%、最大连通成分体积≥128 mm³及内部延伸约束的联合规则。严格集不替代宽松主分析集。
- 图像处理参数、灰度离散化参数、ICC 筛选、特征选择、模型超参数和决策阈值仅在 A 内确定。B 不参与任何参数回改或特征重选。

## 三、输入数据与 ROI 质量控制

### 3.1 图像—ROI 对应关系

- 每个 ROI 必须关联到实际用于勾画的 T2WI 序列。存在多个图像文件时，根据 Slicer 场景引用、图像与掩膜几何信息及 DICOM SeriesInstanceUID 确认目标图像，不按文件名字典序自动选择。
- 图像与掩膜应具有一致的尺寸、间距、原点和方向矩阵；数值比较容差为 `atol=1×10^-3`。
- 几何不一致、参考序列不明确或 ROI 超出图像物理范围的病例暂停处理，完成人工核对后方可进入预处理。
- R1/R2 观察者一致性分析仅纳入两位读者使用同一原始序列的病例；不同序列病例不用于 Dice 或 ICC，直至重新选序列或重新导出 ROI。

### 3.2 ROI 有效性

- 从多标签掩膜提取标签 1，生成肿瘤二值掩膜；掩膜采用整型存储，肿瘤=1、背景=0。
- 肿瘤体素数为 0 的病例排除。
- 原始肿瘤体素数小于 10 的病例列入人工复核；确认 ROI 有效后仍需满足 PyRadiomics 的 `minimumROISize=10` 和 `minimumROIDimensions=2`。
- 记录肿瘤体积、连通域数量、标签集合和图像—掩膜几何状态。
- ROI 使用 3D Slicer 5.8.1 勾画；报告读者数量与经验、勾画序列、是否盲法及分歧处理方式。

## 四、图像预处理

预处理顺序为：输入核验 → 肌肉参照统计 → 重采样 → ROI 裁剪 → 强度归一化 → 输出质控。主分析和各敏感性分析分别保存独立产物，禁止覆盖或混用。

### 4.1 N4 偏置场校正

主分析及预设敏感性分析均不启用 N4，`n4_enabled=false`。

该决策依据 62 例试点：肌肉 CV 中位数为 0.254→0.254，肌肉通路 Original 特征中 ICC>0.75 的数量为 50→52，Z-score 通路为 22→22；30 例高不均匀性病例经 N4 后无一例达到预设去标记标准。残余信号不均匀性作为研究限制报告。

### 4.2 肌肉参照统计

- 主分析采用肌肉均值归一化。肌肉均值在原始分辨率、未重采样图像上计算。
- R1 使用标签 3 作为肌肉，面内 Box 腐蚀半径为 `[1,1,0]` 体素。
- R2 根据标签 2 与标签 3 的平均信号判定肌肉标签，信号较低者作为肌肉；面内 Box 腐蚀半径为 `[2,2,0]` 体素。标签映射逐例写入清单和质控日志。
- 腐蚀后体素少于 50 时逐级减小腐蚀半径；最终半径、肌肉体素数、均值、标准差、CV 和信号百分位均予记录。
- 肌肉 ROI 缺失、平均值非有限或平均值≤0 时标记为预处理失败并人工复核，不自动混入主分析。

### 4.3 图像与掩膜重采样

#### 主分析

- 目标体素间距：`[1,1,2] mm`。
- 图像插值：SimpleITK 三次 B-spline，IBSI 记法为三维 cubic spline interpolation。
- 掩膜插值：三维最近邻；不产生部分体积标签，不进行插值后阈值化。
- 保留原图方向矩阵和原点，不进行 LPS/RAS 重定位。
- 输出尺寸：逐轴计算 `ceil(原尺寸 × 原间距 / 目标间距)`。
- 网格定位：输出索引 `(0,0,0)` 的体素中心与原图原点对齐；该实现不同于 IBSI 参考配置的整幅图像中心对齐方式，按实际算法报告。
- 图像超出原物理范围的采样值设为 0；输出图像转为 float32，不对插值后的灰度值取整。

#### 各向同性重采样敏感性分析

- 目标体素间距：`[2,2,2] mm`。
- 除目标间距外，方向、原点、尺寸计算、图像和掩膜插值、外推值、强度归一化、裁剪、滤波、离散化及特征参数均与主分析一致。
- 该敏感性臂使用主分析锁定的 Original 及各滤波输出 binWidth，不重新根据 `[2,2,2] mm` 图像估计 binWidth，以单独评价重采样间距的影响。

#### 双读者网格

同一序列的 R2 图像及掩膜重采样至对应 R1 的目标网格，使 R1/R2 具有相同尺寸、间距、原点和方向。映射采用恒等物理变换，不进行刚体或形变配准。

### 4.4 ROI 裁剪与边界

- 单读者病例以重采样后的肿瘤掩膜计算包围盒；双读者病例以 R1、R2 肿瘤掩膜并集计算共同包围盒。
- 包围盒每侧外扩 5 个重采样体素；主分析对应约 5 mm×5 mm×10 mm，各向同性敏感性分析对应各方向 10 mm。
- 图像与掩膜使用同一裁剪索引；裁剪后更新原点，保持间距和方向不变。
- Original、Wavelet 和 LoG 均基于相应裁剪图像计算。滤波边界行为由锁定版本的 PyRadiomics、PyWavelets 和 SimpleITK 实现决定，并在补充方法中报告。

### 4.5 跨图像强度归一化

#### 主分析：肌肉均值归一化

以原始分辨率图像中腐蚀后肌肉 ROI 的均值 `μ_muscle` 为参照，对裁剪后的重采样图像作线性缩放：

```text
I' = I / μ_muscle
```

归一化后强度表示相对于肌肉平均信号的无量纲比值。PyRadiomics 的 `normalize` 保持为 `false`，不再执行第二次标准化。

#### 归一化敏感性分析：肿瘤 ROI Z-score

以重采样后肿瘤 ROI 的均值 `μ_tumour` 和标准差 `σ_tumour` 对裁剪图像作：

```text
I' = (I − μ_tumour) / σ_tumour
```

该通路独立保存，仅作敏感性分析。由于肿瘤 ROI 的均值和标准差被构造为约 0 和 1，一阶强度特征的解释应与主分析分开。

### 4.6 预处理质控

每例每读者记录以下指标：

- 归一化前：`μ_muscle`、肌肉体素数、腐蚀半径、p10/p50/p90、CV、面内信号梯度和异常标志。
- 归一化后：同一肌肉 ROI 的均值、中位数、p10/p90 和 CV；肌肉均值应在数值误差范围内接近 1。
- 重采样前后：图像和掩膜尺寸、间距、原点、方向、肿瘤体积、肿瘤体素数及体积相对变化。
- 双读者：R1/R2 图像网格一致性、肿瘤 Dice、体积差和归一化参照比值。
- 按扫描仪厂商、型号和场强分别汇总归一化前后指标；小样本设备仅作描述。

## 五、影像组学特征提取

### 5.1 PyRadiomics 配置

```yaml
imageType:
  Original: {}

featureClass:
  firstorder: []
  shape: []
  glcm: []
  glrlm: []
  glszm: []
  gldm: []
  ngtdm: []

setting:
  resampledPixelSpacing: null
  normalize: false
  interpolator: sitkBSpline
  binWidth: 1.0
  padDistance: 0
  minimumROIDimensions: 2
  minimumROISize: 10
  label: 1
  force2D: false
  distances: [1]
  symmetricalGLCM: true
  weightingNorm: null
  voxelArrayShift: 0
```

`binWidth` 在运行时由锁定参数覆盖。未设置 `resegmentRange` 或 `binCount`，不进行强度重分割或固定箱数离散化。

### 5.2 固定箱宽离散化

- 连续归一化图像直接输入 PyRadiomics，不对整幅图像预先编码为 bin 序号。
- 多数 first-order 特征使用连续强度；Entropy 和 Uniformity 使用离散化直方图。纹理特征使用固定箱宽法（fixed bin size, FBS）。
- Original 图像的 `binWidth=f×σ_A`。`σ_A` 仅由 A 集 R1 肿瘤 ROI 的合并体素计算；f 取 0.1 和 0.25。
- 主分析为肌肉均值归一化、`f=0.25`：`σ_A=0.995233`，`binWidth=0.248808`。
- 肌肉归一化 `f=0.1` 的 `binWidth=0.099523`；Z-score 通路的 `binWidth` 为 0.1 和 0.25。
- Wavelet 和 LoG 各滤波输出使用其在 A 集主分析图像上预先锁定的 `σ_A(filt)×f`。参数保存于 `feature_extract/configs/sigma_a_filters.json`。
- A 集强度范围只用于外推监测；B 中超出 A 参考范围的体素不裁剪、不合并到边界 bin。

PyRadiomics 3.0.1 的 FBS 以 0 对齐箱边界。对箱宽 `W`，首箱下界为不高于 ROI 最低强度的最大 `W` 整数倍，最低强度被分配到第一箱。该实现与 IBSI 在部分重分割配置中以重分割下界或 ROI 最低强度对齐箱边界的参考实现不同。

### 5.3 图像变换与特征数量

- Original：14 个 Shape、18 个 first-order 和 75 个纹理特征，共 107 个。
- Wavelet：PyRadiomics 默认 `coif1`、一级三维 stationary wavelet transform，8 个子带；每个子带提取 18 个 first-order 和 75 个纹理特征，共 744 个，不重复 Shape。
- LoG：三维 Laplacian of Gaussian，σ=1、2、3 mm；每个尺度提取 93 个非 Shape 特征，共 279 个。
- 每个分析臂合计 1130 个特征。
- Shape 仅从相应分析臂的 Original 重采样掩膜提取一次。

### 5.4 三维纹理聚合

- `force2D=false`，全部纹理按三维 ROI 计算。
- GLCM 距离为 1 个体素，使用 3D 方向；矩阵对称化。无方向距离加权，各方向分别计算特征后取均值。
- GLRLM 无方向距离加权，各 3D 方向分别计算特征后取均值。
- GLSZM、GLDM 和 NGTDM 使用 PyRadiomics 3.0.1 的默认三维邻域与聚合实现。
- 各向同性敏感性分析仍采用距离 1 个体素，因此其物理邻域为 2 mm；主分析在 x/y/z 方向对应的物理步长分别为 1/1/2 mm。该差异属于重采样敏感性分析所评价的组成部分。

### 5.5 输出与完整性检查

每个分析臂保存：

- `features_original.csv`
- `features_wavelet.csv`
- `features_log.csv`
- `diagnostics.csv` 与 `diagnostics_filtered.csv`
- `grid_params.csv`
- A/B 强度外推范围报告
- 参数配置和软件版本快照

逐例核对特征数、列名唯一性、Shape 是否仅出现一次、NaN/Inf、ROI 体素数和计算异常。

| 纹理维度与聚合 | 三维；GLCM/GLRLM 按方向计算后平均；GLCM 对称；距离 1；无方向加权 |
| 软件 | Python 3.7.12、PyRadiomics 3.0.1、SimpleITK 2.2.1，并保存完整参数文件 |

## 七、特征质控与观察者间可重复性

1. 在 A 内同序列双读者子集计算 ICC(2,1)，报告点估计与 95%CI；固定预筛选阈值为 ICC>0.75。
2. B 内双读者病例仅描述 Dice、体积差和 ICC，不参与筛选规则制定。
3. A-R1 中存在 NaN 或 Inf 的特征不进入候选池，并记录对应病例和原因。
4. 近零方差筛选、特征标准化及相关性去重均在嵌套交叉验证的每个外层训练折内完成。
5. 相关去重阈值为 `|r|>0.90`；优先保留 ICC 较高的特征，ICC 相同时按特征名称字典序处理。
6. 固定质控产物保存于 `prognosis_analysis/output/qc/stage6_v2/`。

### 8.1 各向同性重采样敏感性评价

`[2,2,2] mm` 分析臂仅改变目标体素间距，并执行以下预设比较：

1. 在 A-R1 中逐特征报告与主分析的 Spearman 相关系数、ICC(A,1)和配对相对差异分布。
2. 在 A 内同序列双读者子集中重新计算 ICC(2,1)，比较 ICC>0.75 特征数量与候选特征重叠率。
3. 按与主分析相同的嵌套交叉验证和特征选择规则独立重建模型；不得使用主分析已选特征替代该分析臂的折内选择。
4. 使用各向同性分析臂在全 A 锁定的参数一次性评估 B，报告与主分析的区分度、校准度和临床净获益差异；不得根据 B 的结果选择最终重采样方案。
5. 各向同性结果作为稳健性证据，不替代主分析结论。

## 九、建模接口与数据泄漏控制

- 阶段六输出的候选特征池是预后建模的唯一影像组学输入。
- 主分析读取 `prognosis_analysis/output/modeling_v2/dataset_primary_raw_A_r.csv` 和
  `dataset_primary_raw_B_r.csv`，二者为宽松高信号筛选后的 A/B 集；严格规则数据集以同目录
  的 `*_strict_r.csv` 文件保存，用于预先定义的敏感性重跑。
- 所有均值/标准差、近零方差筛选、相关性去重、降维、特征选择和超参数优化均限定在外层训练折内。
- 最终模型在全 A 上重新估计全部训练依赖参数并锁定，然后应用于 B。
- 不在 A+B 合并数据上执行 ComBat；设备间残余差异按扫描仪分层报告。
- 当前生境模型、终点、缺失值处理、嵌套交叉验证和B集验证方案见 `生境分析方案与工作流.md`。
