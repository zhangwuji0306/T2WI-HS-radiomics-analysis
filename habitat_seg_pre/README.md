# R1 生境分割结果示例

本目录为本地示例材料。仓库中仅保留本脱敏说明文件；病例级 VOI、ROI、PNG、NRRD 和清单文件均属于本地材料，不纳入仓库。

- 数据范围：仅使用 R1 结果，不引入 R2 结果。
- 生境方案：使用当前冻结的全 A 生境边界，不重新拟合模型。
- VOI 标签：0=背景，1=L（绿色），2=H（红色）。
- 3D 视图：采用候选 B 的斜向下视角，俯视角 `elev=35°`、基准方位角 `azim=45°`；绕 Z 轴旋转 0°、120°、240°，视图仅标注旋转角度，不标注 XYZ 轴。
- 3D 坐标：依据 VOI 文件记录的物理空间坐标计算，未按病例旋转到主轴。
- ROI：使用原始 R1 序列和原始 mask，按原始层面索引截取肿瘤最大面积层面及其上下相邻层面；不使用归一化图像，不进行重采样、插值或空间坐标转换。
- 生境边界投射：固定边界 `b=2.810674`，按每例原始图像的肌肉平均灰度计算 `T_raw=b×μ_muscle(raw)`，再在原始肿瘤 mask 内判定 L/H。
- ROI 显示：mask 不透明度 `alpha=0.42`；PNG 仅进行显示窗宽映射，不改变原始灰度数据。
