# W08 — A-only repeated nested cross-validation implementation protocol

Status: implementation-ready; no formal A-only 50-fold run has been started.

W08 consumes the frozen W04 modeling protocol and the frozen W07 outer split
artifact. The production entry point reads only the code-bound W06 A modeling
population and `prognosis_analysis/output/outer_splits_A.csv`. An authorized
A-only feature frame is supplied in memory by the upstream reader; W08 does
not accept an arbitrary feature path and does not open any B artifact.

## Frozen model set

The implementation exposes exactly the W04 models and populations:

| Model | Predictors | Population | Family |
|---|---|---|---|
| M0 | C | main | unpenalized Breslow Cox PH |
| M1 | C + `H_high_fraction` | main | unpenalized Breslow Cox PH |
| M2 | C + G | main | unpenalized Breslow Cox PH |
| M3L | C + G + R_low | R_low | Elastic-Net Cox |
| M3H | C + G + R_high | R_high | Elastic-Net Cox |
| M4 | C + G + R_low + R_high | dual-radiomics | Elastic-Net Cox |
| M5 | C + W | W-available | Elastic-Net Cox |

The narrower populations use explicit structural and technical availability
flags. Structural absence is never converted into zero or ordinary missingness.
The M2 comparator is refit on the same eligible patients when paired with a
radiomics model by the shared W07 repeat/fold assignment. The fixed execution
units include M0 on W-available patients, M2 with R_low, M2 with R_high, M2 on
the dual-radiomics population, and the corresponding M3L/M3H/M4 runs.

## Fold boundary

For each outer repeat/fold and each eligible population, the provider is called
with outer-training IDs only. It fits patient-balanced K=2 centers from the
training supervoxel representation, orders them H-low/H-high, and uses their
midpoint as the boundary. It then transforms outer training and validation
with the same immutable state. The provider contract makes fold-specific G and
R_low/R_high regeneration explicit; a provider that does not perform this fit
is rejected before modeling.

## Training-only model path

Clinical preprocessing uses training-fold median/mode imputation, fixed
predeclared categorical levels and training-only continuous scaling. For
radiomics, the fixed sequence is training-only imputation, near-zero variance
filtering, absolute-Pearson correlation reduction at `>0.90`, training-only
z-scoring, inner-CV alpha/lambda selection, and outer-training refit.

The alpha grid is `[0.1, 0.5, 0.9, 1.0]`. Each inner-training fit derives its
own `lambda_max` and evaluates 100 log-spaced ratios from `1` through `1e-4`.
Selection uses mean inner-validation Uno C-index only. Ties within `1e-12`
choose the larger lambda, then the smaller alpha in frozen grid order. Every
candidate is attempted; low-penalty numerical stabilization uses stable
risk-set sums, bounded exponentiation and deterministic step backtracking,
and is recorded in the fold audit rather than used to remove candidates.

## Outputs and isolation

The library returns in-memory held-out predictions, fold metrics, and selection
records. The repository contains only the result and audit schemas; no formal
patient-level W08 output is generated by this implementation task. Every fold
records training/validation ID hashes, the W04/W07 hashes, seeds, fold centers
and boundary, preprocessing decisions, candidate counts and stability actions.
`outer_validation_used_for_selection` is false, and all B-access flags remain
false.
